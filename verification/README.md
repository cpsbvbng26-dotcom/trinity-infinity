# 独立検証

`independent_check.py` は、系列の主張を**論文に同梱されている検証スクリプトとは別に**書いたものです。
同じ記述から独立に実装したときに同じ結論に達するかを見るためのものなので、既存のスクリプトの写しではありません。

```
python3 independent_check.py
```

NumPy のみを必要とします。乱数種は固定してあるので、何度実行しても同じ数値が出ます。
各項目が PASS / FAIL の 1 行を印字し、13 項目すべてが通ると終了コード 0 を返します。

## 何を確かめているか

**A — 残った定理。** `f(x) = αQx + (1−α)p` について、変位がちょうど α 倍されること、
不動点が閉形式 `(1−α)(I−αQ)⁻¹p` と一致すること、誤差がちょうど αᵏ で減衰すること。
巡回置換について n = 2, 3, 4, 5, 8 で確認します。

なお、Series I の記述は `‖Tₙ − T*‖ ≤ αⁿ‖T₀ − T*‖` と不等号ですが、線形部分がちょうど
α × 等長写像なので**等号が成り立ちます**。24 反復まで、差は 1.1×10⁻¹⁶ 以内です。

**B — 本質的でなかった三つの前提。** 証明が使っているのは「Q が長さを変えない」ことだけです。

- 置換でなく回転（n = 4）でも同じ
- 行列式 −1 の鏡映（n = 5）でも同じ
- ランダムな直交行列（n = 6）でも同じ
- 単位立方体の外、±50 の範囲から始めても同じ

つまり、三要素であることも、巡回置換であることも、状態空間が [0,1]ⁿ であることも、
収束には効いていません。

**C — 異方性の縮小定数。** Series II の maxᵢ aᵢ は「タイトな上界」ではなく、
`DQ`（D = diag(a)）の**作用素ノルムそのもの**です。スペクトルノルムはユニタリ不変なので
`‖DQ‖₂ = ‖D‖₂ = maxᵢ aᵢ`。20,000 方向の経験的上限と照合して 10⁻¹² 以内で一致します。

**D — 残らなかった主張。** 改訂前の作用素（自己言及的な統合）を記述どおり実行すると、
極限が初期値に依存します。1000 回の試行で、極限の平均 0.5052、標準偏差 0.1655、範囲 [0.0437, 0.9422]。

Series I が別実装で報告した値は 平均 0.4995、範囲 [0.0403, 0.9589] でした。
**別々に書かれた二つの実装が、同じ記述から同じ結論に達しています。**

## 出所

このスクリプトは、系列の内容を読んだうえで Claude Code（Anthropic）を用いて書かれ、実行されました。
論文本体には含まれていません。数値はすべて実行して得たものです。
