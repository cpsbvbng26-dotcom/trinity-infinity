# independent_check.py —— 定理は正しいか

## 何を確かめているか

**A — 残った定理。** `f(x) = αQx + (1−α)p` について、変位がちょうど α 倍されること、
不動点が閉形式 `(1−α)(I−αQ)⁻¹p` と一致すること、誤差がちょうど αᵏ で減衰すること。
巡回置換について n = 2, 3, 4, 5, 8 で確認します。

なお、Series I の記述は `‖Tₙ − T*‖ ≤ αⁿ‖T₀ − T*‖` と不等号ですが、線形部分がちょうど
α × 等長写像なので**等号が成り立ちます**。24 反復まで、差は 1.1×10⁻¹⁶ 以内です。

**B — 本質的でなかった三つの前提。** 証明が使っているのは「Q が長さを変えない」ことだけです。

- 置換でなく回転（n = 4）でも同じ
- 行列式 −1 の鏡映（n = 5）でも同じ
- ランダムな直交行列（n = 6）でも同じ
- 単位立方体の外、±50 の範囲から始めても同じ

つまり、三要素であることも、巡回置換であることも、状態空間が [0,1]ⁿ であることも、
収束には効いていません。

**C — 異方性の縮小定数。** Series II の maxᵢ aᵢ は「タイトな上界」ではなく、
`DQ`（D = diag(a)）の**作用素ノルムそのもの**です。スペクトルノルムはユニタリ不変なので
`‖DQ‖₂ = ‖D‖₂ = maxᵢ aᵢ`。20,000 方向の経験的上限と照合して 10⁻¹² 以内で一致します。

**D — 残らなかった主張。** 改訂前の作用素（自己言及的な統合）を記述どおり実行すると、
極限が初期値に依存します。1000 回の試行で、極限の平均 0.5052、標準偏差 0.1655、範囲 [0.0437, 0.9422]。

Series I が別実装で報告した値は 平均 0.4995、範囲 [0.0403, 0.9589] でした。
**別々に書かれた二つの実装が、同じ記述から同じ結論に達しています。**

# claims_audit.py —— 印字された数字は、その通りに出るか

論文の紙面から数値を書き写し、その隣に計算し直した値を並べます。判定は三つです。

| | |
| --- | --- |
| `MATCH` | 印字された値と計算値が、示した許容差の中で一致する |
| `CONSISTENT` | 乱数を使う主張なので一致は求められない。分布の理論値と整合する |
| `MISMATCH` | 一致しない |

31 項目のうち 27 が `MATCH`、4 が `CONSISTENT`、`MISMATCH` は 0 です。

## Series I（13 項目）

補正した作用素の不動点 `(0.510204, 0.306122, 0.183673)` を閉形式から計算し、さらに
**閉形式を信じずに** 5 点から 400 回反復して同じ点に着くことを確かめます（差 10⁻¹⁶ 台）。
第3節の利得表は πC(n)=n+1, πD(n)=n+2 という定義から 8 行を生成し直して 1 行ずつ突き合わせ、
裏切りの強支配とパレート支配も判定します。閾値 δ*=1/2 は 200 万点の格子で
VC ≥ VD が最初に成り立つ δ を探して確かめます。

自己言及的な統合（撤回された方）については、乱数の再実行より強いことが言えます。
**極限は初期値の三成分の平均に等しい**ので、その分布は解析的に分かります —— U(0,1) 三個の平均は
平均 1/2、標準偏差 1/6 = 0.16667。論文の報告値 0.4995 / 0.1676 はこの理論値と整合します。

## Series II（13 項目）

異方的な不動点 `(0.754190, 0.527933, 0.508380)`、20,000 組の経験的な縮小比、
離散時間の `V(xₙ₊₁) ≤ max(aᵢ)² V(xₙ)`、ミニマックス利得 2。

第4節の**凸包**は SciPy を使わずに計算します。8 点なので全ての 3 点組から支持超平面を総当たりで拾い、
同一平面上の点をまとめて面を作り、扇状に分割して体積を出します。結果は **4.000000、面 6 枚**
（論文の 4.00 と一致）。端点かどうかは、その点を除いて凸包を作り直し、体積が真に減るかで判定します
（8 点すべてが端点）。

第6節は 3閉路のグラフラプラシアンの固有値 0,3,3、ρ(0.25K)=0.75、200 項の部分和と閉形式の差
2.7×10⁻¹⁵（論文は 3×10⁻¹⁵ 以内）、`K∞` の行列一致。

## Series III（5 項目）

表1 を n=2〜8 で作り直します。等長写像の誤差は全て厳密に 0、閉形式の不動点への最大偏差は 1.1×10⁻¹⁶、
`P² = I` となるのは n=2 のみ —— **論文の表1 の三列がそのまま再現します。**
加えて、収束の速さが n に依存しないことを 24 反復まで確認します。
