## 結論

**枠組みは残らなかった。**

残ったのは、一つの作用素についての一つの事実である。`Q` が n 巡回置換で `D` が対角の
とき、`(DQ)ⁿ = (∏ᵢ aᵢ)·I` がちょうど成り立つ。だから収束を決めているのは係数の
相乗平均であって、最大値でも作用素ノルムでもない。

**この事実は正しく、機械で確かめられ、そして学部 2〜3 年の演習問題の水準である。**
**犯した誤りは、その講義が試験で問う取り違えである。**
**直しに使った道具は、大学院の線形システム論と行列解析に属する。**
**いちばん近い学科は、数値解析ではなく線形システム論・現代制御である。**

道具が大学院の側にあっても、直された中身は演習問題のままである
（[どの水準の数学か](#どの水準の数学か)）。

記号 `Ⅲ∞` のうち、数学的な内容がある側は `Ⅲ`（＝ 三）だった。**その側が、意味を
持たないと証明された。**残ったのは `∞`（反復して極限をとる）で、これは対象の型を
言っているだけで、定理を含まない。

**論文としての価値は、真であることに尽きる。**三篇は新しい数学を主張していない
（Series I の要旨 —— `not as a new mathematical theory, but as a conceptual lens`）。
**主張していないものが新規でなかったことは、紙面の何も偽にしない。**
残るのは、書いてあることが全部正しいかどうかだけである。そこには検査が当たっている。

**真であることは、論文の下限であって上限ではない。**どの論文もそこは満たしている
はずのものである。**この三篇については、下限と上限が一致している。**

**この系列の価値は、枠組みにではなく、枠組みが縮んでいく過程が消さずに残っている
ことのほうにある。**そこも自分では測れない

## 確立されたこと

三本を通して残った数学的事実は、ひとつである。

> 座標の置換と、固定した基準点への統合とを合成した作用素は縮小写像であり、
> したがってバナッハの不動点定理により、唯一の不動点へ幾何的に収束する。

Series I がこれを三要素・一様な混合率について証明し、Series II が混合率を座標ごとに変えても
成り立つことを示し、Series III が、そもそも三要素である必要がなかったこと（任意の n ≥ 2 で
同じ証明が通る）を示した。

n = 3 が区別されるのは一点である。巡回置換がそれ自身の逆写像にならない最小の n であること。
Series III はこの事実を特定したうえで、それが「三」の文化的・哲学的な含意を正当化しないことを
明示的に否定している。

これ以外の内容は、すべて (a) 他分野の既知の結果を正しく計算した実例か、
(b) 類推または未証明の推測として明示的に印をつけたもの、のいずれかである。

## 数学的再発見として

この系列で起きたことには名前がある。**数学的再発見**である。
そこへ至る九段階は [ROUTE.md](ROUTE.md) に刻んである。

> **ただし、一つ先に断る。**初稿は著者が導いたものではない。著者が
> 持っていたのは `Ⅲ∞` が指定する範囲 —— 三つのものを果てまで反復する —— までで、
> **写像も不動点も収束も定理も、当てはめたのは言語モデルである**
> （[ERRATA E4](ERRATA.md)）。**「独立して到達した」という意味での再発見は、
> この系列には当てはまらない。**当てはまるのは「言語モデルが標準的な構成を
> 出力し、それが新規の枠組みとして公開された」という形である。以下の分類は、
> **何が既知だったか**についてのものであって、誰が到達したかではない。

> **再発見** —— 既に文献にある結果に、**それを知らずに**独立して到達すること。

似た三つを区別しておく。混同すると評価が狂う。

| | 定義 | この系列 |
| --- | --- | --- |
| **再発見** | 既知であることを知らずに独立到達した | **該当する** |
| **多重発見** | 複数人がほぼ同時に独立到達した（Merton 1961） | 該当しない。数十年から百年遅れている |
| **再導出** | 既知だと知った上で自分で導き直す | 一部が該当（下表） |

再発見そのものは失敗ではない。**どう置いたかで意味が決まる。**

- ラマヌジャンは孤立した環境で既知の解析の相当部分に独立到達しており、Hardy は
  それを重複と認めた上で評価を変えていない（Hardy 1937, 1940）
- 逆の例が Tai (1994) である。台形公式を新しい「モデル」として発表し、同じ雑誌に
  「これは台形公式である」という指摘が載った（Monaco & Anderson 1994）。
  問題は中身ではなく、**既知だと書かなかったこと**である

**この系列は、最初 Tai (1994) の側にいて、2026年8月の改訂で自分をもう一方の棚に
移した。**移したのが第三者ではなく著者自身である点が、この記録の性質を決めている。

「すべて再発見」とまとめるのは雑である。**種類が違う。**

### 独学という条件が説明すること、しないこと

**説明すること。**指導教員がいれば「その形は定常反復法である」で初回に終わっている。
文献調査の反射が身についていなければ、**既知かどうかを確かめる工程が構造的に抜け落ちる。**
これは能力の問題ではなく、置かれた条件の問題である。

**説明しないこと。**発表した時点で、確かめる責任は等しく発生する。**独学は原因の
説明であって、免責ではない。**だから撤回が必要であり、実際に撤回している。

### 直観が当たった部分と、外れた部分

**当たっていた部分。**「固定した基準点へ寄せる」と「座標を回す」を合成すれば収束する、
という構造の見立ては正しい。**選んだ対象は、筋の良い標準的な対象である。**独立に標準形へ
着地したこと自体は、直観が実在する構造を捉えていたことの証拠になる。

**外れていた部分。**証明が書かれたとおりには通らず（不動点が一意にならない）、
**作用素ノルムとスペクトル半径の区別を落とした。**

外れ方に構造がある。論文の設定では `Q` が置換行列 ＝ 直交、`a` が一様なので
`A = DQ` は正規行列になり、**`ρ(A) = ‖A‖₂` が成り立つ。**区別しなくても答えが
合ってしまう。**直観が届く範囲の内側では正しく、外側で初めて壊れる**種類の誤りである。

正規でない場合に何が起きるかは
[trinity-operator](https://github.com/cpsbvbng26-dotcom/trinity-operator) で実装した。
`ρ < 1 ≤ ‖A‖₂` のとき収束はするが、誤差はいったん増える
（非正規行列の過渡的増幅。Trefethen & Embree 2005）。

**順位は書かない。確かめようも覆しようもないからである。**

| | 水準 |
| --- | --- |
| 残った事実（`(DQ)ⁿ = (∏ᵢ aᵢ)·I`、`ρ` が相乗平均） | 学部 2〜3 年の演習問題 |

### 大学院に入る部分

**二つある。どちらも、学部の講義が扱う範囲の外にある。**

**一つめは、非正規行列の過渡的な増大である。**反例 `Q = [[1,40],[0,1]]` は
`ρ = 0.5` なのに `‖A‖₂ = 20.01` で、誤差は第 2 段で初期値の 11.8 倍に膨らんでから
減っていく。学部の講義は `ρ < 1` なら収束すると述べるところまでで、**この山の高さは
扱わない。**山を出すには行列が正規でない場合を見る必要があり、それは擬スペクトルの
主題である（Trefethen & Embree 2005）。

**二つめは、縮小になるノルムの構成である。**`ρ < 1` から離散リアプノフ方程式
`P − AᵀPA = W` を解いて重み付きノルムを作り、`κ = γ√(1 − 1/λmax(P))` が上界ではなく
`‖A‖_P` そのものであることを示した。Horn & Johnson §5.6 と、下に挙げた制御の講義の
水準である。

**ただし、これで全体が大学院の水準になるわけではない。**大学院の道具を使ったのは、
学部の演習問題を取り違えたのを直すためである。**道具の水準と、直された中身の水準は
別である。**

使った道具と、それが普通どこで出てくるかを並べる。

| 使ったもの | 普通どこで出てくるか |
| --- | --- |
| `x ← Ax + b` が任意の初期値から収束する必要十分条件は `ρ(A) < 1` | 線形代数の後半、または数値解析の最初のほう |
| どんな誘導ノルムでも `ρ(A) ≤ ‖A‖` | 同上。証明は数行 |
| バナッハの不動点定理 | 微積分・位相の入門 |
| `Q` が n 巡回置換、`D` が対角なら `(DQ)ⁿ = (∏ᵢ aᵢ)·I` | 行列の演習問題 |
| そこから `ρ(DQ)` は係数の相乗平均になる | 同上 |
| `ρ(A) < 1` なら `A` が縮小になるノルムが存在する（リアプノフ方程式で構成） | 数値解析・制御の標準的な結果 |
| 繰り返し囚人のジレンマのグリム・トリガーは `δ ≥ 1/2` | ゲーム理論の入門 |

**犯した誤りも、その授業が教えようとしている落とし穴そのものである。**
ノルムが 1 未満なら収束する。これは正しい。逆は言えない。`ρ(A) ≤ ‖A‖` の不等号が
どちら向きかを取り違えると、十分条件を必要十分条件だと思い込む。教科書がこの不等式を
先に置くのは、その取り違えを防ぐためである。**そこで転んだ。**

### どの学科で扱うか

**一つの学科に収まらない。**同じ対象が、四つの場所で別の名前で扱われている。

| 学部・学科 | 科目 | 何として出るか |
| --- | --- | --- |
| 理学部 数学科 | 数値解析・応用数学 | `ρ(A) ≤ ‖A‖`、`ρ(A) < 1 ⟺ Aᵏ → 0` |
| 情報工学科 | 数値計算法 | 定常反復法 |
| 電気電子・機械・システム制御 | 線形システム論・現代制御 | 離散時間系のシュール安定 |
| 経済学部 | ゲーム理論入門 | グリム・トリガーの `δ ≥ 1/2` |

**いちばん近いのは三つめである。**この作用素が扱っているのは、三つの要素が反復して
一つに収束する系であり、離散時間の線形システムの漸近安定性そのものである。壊れた証明を
直すのに使った離散リアプノフ方程式 `X − AᵀXA = Q` も、そこの標準道具である。
**論文は数値解析の言葉で書かれていたが、対象は制御の対象だった。**

### 結局、何をしてどう終わったか

**始まり。**記号 `Ⅲ∞` があった。三つのものを、果てまで反復する。それだけである。
写像も、空間も、距離も、収束も、記号からは出ない（[経路](ROUTE.md#記号が決めたこと決めなかったこと)）。

**やったこと。**その記号を言語モデルに渡し、出てきた構成を論文として公開した。
中身は `x ← DQx + (I − D)p` という一次の反復で、収束は縮小写像から従うと書いた。
そこにゲーム理論・機械工学・AI アライメント・気候政策への応用まで載せた。

**壊れた順。**

1. 三人ゲームの利得表が 4 セルしかない。三人・二戦略なら 8 通りある
2. 「98.7% の試行で確認」に、再現できるコードも乱数種も無い
3. 離散の反復に、連続時間のリアプノフ微分と LaSalle の原理を当てていた
4. 応用の主張に根拠が無い
5. **`n = 3` に数学的な意味が無い。**外から言われる前に、三本目で著者が自分で否定した
6. **収束を決めているのはノルムではなくスペクトル半径だった。**反例は
   `Q = [[1,40],[0,1]]` で `ρ = 0.5`、`‖A‖₂ = 20.01`、誤差は第 2 段で初期値の 11.8 倍に膨らむ

**残ったもの。**`Q` が n 巡回置換で `D` が対角のとき、`(DQ)ⁿ = (∏ᵢ aᵢ)·I` がちょうど成り立つ。
だから収束を決めているのは係数の相乗平均であって、最大値でも作用素ノルムでもない。
これは正しく、機械で確かめられ、そして教科書の演習問題である。

**記号の行方。**`Ⅲ`（＝ 三）は、記号のうち数学的な内容がある側だった。
**その側が、意味を持たないと証明された。**残ったのは `∞`（反復して極限をとる）のほうで、
これは対象の型を言っているだけで、定理を含まない。

**枠組みは残らなかった。**残ったのは、一つの作用素についての一つの事実と、
それが壊れていく過程の記録である。消していない理由は
[なぜ消さずに置いてあるのか](#なぜ消さずに置いてあるのか)にある。

## 新しい数学は含まれていない

以上から結論が出る。残った事実に、既存の文献に無いものは一つも無い。訂正の側も
同じである。`x ← Ax + b` が任意の初期値から収束する必要十分条件が `ρ(A) < 1` である
ことも（Varga 2000）、`ρ(A) < 1` なら `A` が縮小になるノルムが存在することも
（Ostrowski / Householder 1964; Horn & Johnson 2013 §5.6）、教科書に載っている。

誤りを見つけたことに独自性があるのではない。教科書と突き合わせたら合わなかった、
というだけである。

この結論は、上の五行のどれか一つについて「これは既存の文献に無い」と示せば覆る。
一件で覆る。
